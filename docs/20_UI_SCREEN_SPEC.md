# UI Screen Specification

## Auth
- Login
- Forgot/reset password
- Invite acceptance

## Dashboard
Cards:
- active conversations
- leads
- appointments
- handoffs
- AI usage.

## Inbox
Three-column desktop layout where practical:
1. conversation list
2. message thread
3. customer/context panel.

Actions:
- assign
- handoff
- resolve
- add note
- view lead
- view appointment.

## Knowledge
- document list
- upload
- status
- search
- reindex
- delete.

## Agents
For each agent:
- enabled toggle
- name
- description
- tone
- instructions
- knowledge sources
- allowed tools
- escalation rules.

## Integrations
Cards:
- provider status
- connect/disconnect
- scopes
- last sync
- error state.

## Analytics
Charts/tables:
- conversations over time
- agent distribution
- handoff rate
- leads
- appointments
- usage.

## Settings
- business
- team
- roles
- widget
- AI
- notifications
- retention.
